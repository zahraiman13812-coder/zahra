# پورتفولیوی زهرا ایمانی فرد

یک وب‌سایت شخصی فارسی و RTL با Next.js 15، React، Motion Primitives و پنل مدیریت واقعی برای ثبت و ویرایش نمونه‌کارها.

## راه‌اندازی

نیازمندی: Node.js 20 یا جدیدتر.

```bash
npm install
cp .env.example .env.local
```

مقادیر `ADMIN_PASSWORD` و `SESSION_SECRET` را در `.env.local` با مقادیر قوی و اختصاصی جایگزین کنید. مقدار `SESSION_SECRET` حداقل باید ۳۲ کاراکتر باشد. سپس:

```bash
npm run dev
```

- سایت: http://localhost:3000
- پنل مدیریت: http://localhost:3000/admin

برای انتشار در سرور:

```bash
npm run build
npm run start
```

## امکانات

- طراحی واکنش‌گرا، راست‌به‌چپ و بخش‌های درباره من، نمونه‌کارها، خدمات و ارتباط.
- انیمیشن‌ها با استفاده از کامپوننت‌های **TextEffect**، **AnimatedGroup** و **Magnetic** از فایل Motion Primitives ارسالی (کد آن‌ها در `components/motion` قرار داده شده).
- مدیریت پروژه‌ها: ایجاد، ویرایش، حذف، انتشار/پیش‌نویس، عنوان، دسته‌بندی، توضیح، تگ‌ها، لینک پروژه و GitHub، تصویر با URL یا آپلود.
- لاگین با کوکی امضاشده، HttpOnly، SameSite Strict و رمز عبور تنظیم‌شده روی سرور.
- SEO metadata، ریسپانسیو و پشتیبانی از کاهش حرکت.

## نکات مهم شخصی‌سازی

1. **سه پروژه موجود صرفاً محتوای نمونه و تخیلی هستند**؛ آن‌ها را از `/admin` حذف یا با پروژه‌های واقعی جایگزین کنید.
2. ایمیل `hello@example.com` در `components/portfolio.tsx` یک **جای‌نگهدار** است؛ قبل از انتشار آن را به ایمیل واقعی خودتان تغییر دهید.
3. فهرست فناوری‌های `skills` در `components/portfolio.tsx` پیشنهاد اولیه است؛ مهارت‌های واقعی خودتان را جایگزین کنید.
4. برای نمایش تصویر پروژه کافی است از پنل آپلود کنید یا آدرس تصویر را وارد کنید. آپلود فقط PNG/JPEG/WebP/GIF تا ۵ مگابایت است.

## نکات استقرار و ذخیره‌سازی

پروژه‌ها در `data/projects.json` و تصاویر در `public/uploads` روی **دیسک سرور** ذخیره می‌شوند. این پیاده‌سازی برای یک پنل تک‌مدیر روی VPS/هاست Node با دیسک ماندگار مناسب است و **روی سرویس‌های serverless با فایل‌سیستم موقت (مثل استقرار معمول Vercel) برای CMS مناسب نیست**. در صورت استفاده از Vercel باید دیتابیس و Object Storage (مانند PostgreSQL + S3/R2) جایگزین شوند.

برای استقرار با دایرکتوری پایدار سفارشی از `DATA_FILE` و `UPLOAD_DIR` استفاده کنید؛ دقت کنید آپلودها برای سرو عمومی باید از مسیر `/uploads/...` قابل دسترسی باشند. برای تولید پرحجم یا چند ادمین، ذخیره‌سازی JSON را با دیتابیس، نسخه‌بندی و قفل نوشتن جایگزین کنید. برای سایت عمومی HTTPS فعال کنید، نرخ ورود را محدود کنید و رمز قوی قرار دهید.
